# 全球跨境智能爆品预测选品系统

一款面向跨境电商卖家的多平台、全区域、全周期爆品预测与痛点反向拆解选品工具。

## 核心功能

### 1. 爆品预测中心
- 支持按地区、平台、时间节点筛选潜力爆品
- 6大时间节点完整数据集：万圣节、黑五网一、圣诞节、情人节、返校季、实时飙升趋势
- 每个产品包含机会分数、搜索增长率、竞品数量、利润空间、进入门槛、核心痛点

### 2. 爆品痛点反向拆解引擎（核心差异化）
- 六大维度痛点热力分布：产品质量、功能体验、规格适配、场景适配、包装物流、合规安全
- 真实差评原文库（中英对照）
- 竞品缺陷对标与行业共性痛点识别
- 基于痛点的产品改进建议与成本评估

### 3. 趋势追踪看板
- 搜索热度趋势预测
- 品类机会分布
- 供需比变化曲线

### 4. 竞品深度分析
- 竞品价格波动追踪
- BSR排名变化
- Review增长分析

### 5. 利润测算工具
- 全球物流费率、平台佣金、关税税率数据库
- ROI、保本销量、库存周转天数自动计算

### 6. 选品组合推荐
- 节日款+通用款搭配策略
- 关联产品推荐，降低滞销风险

### 7. 关键词研究中心
- 长尾词挖掘
- 竞品流量反查
- CPC与转化率分析

### 8. 供应链货源匹配
- 1688工厂对接
- 阶梯报价分析
- 供应商评分对比

### 9. 库存备货预测
- 销量预测
- 补货时间预警
- 多方案备货对比

### 10. Listing优化助手
- AI文案生成
- 关键词埋词检测
- 痛点关键词反向推导

### 11. 合规风险检测
- 认证要求清单
- 专利侵权预警
- 各国合规要求对比

### 12. 跨站点机会对比
- 全球多站点六维雷达对比
- 市场容量、竞争度、利润空间综合评估

## 支持的地区
美国、加拿大、英国、德国、法国、日本、东南亚、中东

## 支持的平台
Amazon、TikTok Shop、TEMU、SHEIN、eBay、Shopify

## 技术栈
- 原生 HTML/CSS/JavaScript 单文件应用
- ECharts 5.6.0 数据可视化
- 无框架、无构建工具，开箱即用

## 使用方法
1. 直接用浏览器打开 `index.html`
2. 选择目标地区、平台、时间节点
3. 点击「重新生成分析」按钮获取对应数据
4. 浏览各模块的选品分析结果

## 数据说明
当前版本为演示原型，数据基于各平台真实消费趋势构建。如需接入真实平台数据，可对接：
- Amazon SP-API
- TikTok Shop API
- Google Trends API
- 第三方选品工具API（Jungle Scout、Helium 10等）
